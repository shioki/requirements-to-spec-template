# プロンプト例: 会議メモから要求仕様書を起こす

会議メモやチャットの断片を、[`template.md`](../../template.md) の形に変換するときに使います。小規模なら [`template-lite.md`](../../template-lite.md) を指定してください。

```text
あなたは要求仕様の編集者です。以下の会議メモを、指定したテンプレートの見出しに沿って要求仕様書に変換してください。

制約:
- IDは日本語プレフィックスを使う。業務-XX / 利用-XX / 機能-XX / 非機能-XX / 制約-XX / 連携-XX / 前提-XX / 未解決-XX / データ-XX / 画面-XX / 権限-XX / 文言-XX / リスク-XX / 試験-XX。ドキュメントIDは要件-XXXX
- 優先度は 必須 / 推奨 / 任意。スコープは スコープ内 / スコープ外
- 機能要求は「[条件/トリガー] のとき、システムは [動作] する」と書く
- 機能ごとに受け入れ基準(条件、入力、期待結果、異常系、境界値)を書く。チェックボックスの [x] はレビューで合意済み、[ ] は未合意
- 「適切に」「なるべく」「可能な限り」は使わない。数値・条件・測定方法で書く
- メモにあって決まっていない事項は本文に書かず、未解決-XX に担当者と期限の欄を空欄のまま残す
- 括弧は半角 () を使う
- メモに無い機能や数値を補わない。足りない情報は未解決事項にする
- 出力はテンプレートの見出し順の Markdown だけにする

テンプレート:
(ここに template.md または template-lite.md を貼る)

会議メモ:
(ここにメモを貼る)
```
